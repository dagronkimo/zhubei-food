# 竹北三餐・今天吃什麼

以竹北中央路189號為中心的早餐／午餐／晚餐網頁（各取最近 50 間）（GitHub Pages）。

- `index.html`：今天三餐、這週三餐總表
- `breakfast.html`／`lunch.html`／`dinner.html`：各餐的轉盤、一週行程、投票＋揪團點餐、地圖、名單、聚餐紀錄
- `shops_b.json`／`shops_l.json`／`shops_d.json`：各餐店家名單（網頁「📤 發布給大家」會開 GitHub issue，由 Actions 自動更新）

資料來源：Google 地圖（2026 年 11 月）。篩選：Google 4.2 星以上、400 則評論以上，不含 $$$$；各餐取離中心最近的 50 間。
